How it works
  • One source. The computer scans the folders and writes each book into your MEGA folder as a pack of pages.
  • Readers are read-only. A shared MEGA folder cannot be written to, so a device can never damage the library.
  • Paste once. Every device uses the same link; new books appear in it without re-sharing anything.
